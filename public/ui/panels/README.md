# 마나 패널 이미지

`mana-panel.webp`를 이 폴더에 넣으면 양쪽 마나 패널 배경에 자동 적용됩니다.

- 파일 경로: `public/ui/panels/mana-panel.webp`
- 권장 제작 크기: **640 × 960 px**
- 화면 비율: 세로형 **2:3**
- 표시 방식: `background-size: contain` — 패널 비율이 달라도 원본 전체가 표시됩니다.
- 안전 영역: 중앙 70% 안에는 무늬를 단순하게 유지하세요. 마나 수치와 버튼이 위에 표시됩니다.
- 권장 형식: WebP, sRGB

실제 패널은 데스크톱에서 폭 196–232px이며 화면 높이에 따라 세로 크기가 달라집니다.
