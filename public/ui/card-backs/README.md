# 통합 카드 뒷면 이미지

`card-back.webp`를 이 폴더에 넣으면 라이프, 상대 손패, 선택 화면의 비공개 카드가 모두 같은 이미지로 표시됩니다.

- 파일 경로: `public/ui/card-backs/card-back.webp`
- 권장 제작 크기: **1000 × 1400 px**
- 화면 비율: 카드와 같은 **5:7**
- 표시 방식: `background-size: cover`
- 안전 영역: 가장자리 4% 안쪽에 주요 문양을 배치하세요.
- 권장 형식: WebP, sRGB

CSS로 만든 기존 원형·십자 문양은 표시되지 않습니다.
